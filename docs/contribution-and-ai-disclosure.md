# Contribution and AI-Assistance Disclosure

## Project ownership

- **Project organization:** Individual student project.
- **Project title:** SecureExam — ESP32-Based Mobile Activity Detection and Remote Invigilator Notification.
- **Student role:** Project owner and final decision-maker for project scope, hardware selection, integration, testing, and academic submission.

## Student contribution

The student should claim only work personally performed. The project owner is responsible for verifying and updating this list before formal submission.

- Project idea, intended application, and project direction.
- Selection and assembly of the actual hardware, where personally completed.
- Uploading and testing the firmware on the physical ESP32, where personally completed.
- Operating the dashboard and recording observations, where personally completed.
- Final design choices, validation, and interpretation of results.

## AI-assisted work

AI assistance was used during development to support tasks such as:

- Structuring and explaining the ESP32 Wi-Fi/BLE scanning logic.
- Drafting or refining firmware and browser-dashboard implementation.
- Explaining serial communication, device-table logic, and alert conditions.
- Preparing repository organization, README content, architecture/algorithm documentation, and testing checklists.
- Identifying potential implementation limitations for the student to review.

## Attribution boundary

The repository preserves the supplied firmware and supplied HTML dashboard as source files. Documentation and repository organization were prepared with AI assistance. The student must review the files, verify behavior on the real hardware, and correct this disclosure if any listed activity does not accurately describe the work performed.

AI assistance does not constitute independent hardware testing, measurement, or proof that the prototype achieves its intended performance.
